# rc7 generalized screening verification

Build source: `691d42cc6dcba86f555f60f7a3ca7e9cb5491211`, following implementation
`f5b9516`, from rc6 baseline `eee5d3a64cb4ecc2409ecf4f853b6322c926d86b`.
This verification record does not alter the candidate application or release bytes.
The original packaging baseline in release.json is not the rc7 source commit.

The ordinary suite passed 429 pytest cases (390 baseline plus 39 new), with two
third-party deprecation warnings. A final repeat passed all 39 affected cases and
the nine release-build cases. Repeats and nested harness groups are not additional
ordinary pytest cases. An earlier stalled run was stopped; the complete verbose
run passed, including the slow wheel-install test.

Four native Arc C groups passed in both source and isolated packaged runtimes:
criterion dialog/no defaults/no-ML/keyboard; synthetic multi-class evidence,
run-once reuse and display-only outlines; manual override separate from review
with v3 project freeze/export and unchanged v1; collection evidence reuse without
inherited review and explicit v3 collection export. Six packaged Arc B groups
also passed, including independent reviews, scoped policies/overrides, v2 freezes,
light/dark layouts at 850x690 and 1260x940 at 100% scale, old v1 reassembly and
1,629-candidate collection scale. The older rc6 verifier rejected both v3 scopes.

Both real supported models completed inference on one public PyTorch Hub dog
image with registered full weight hashes and the exact published vocabulary.
MobileNet retained three detections in 19.99 seconds and ResNet sixteen in 15.13
seconds of service-operation time. Later criteria reused saved observations.
This is integration evidence, not labeled accuracy validation. The explicit
fixture thresholds are not production recommendations.

The same 1,629-candidate project/1,101-member collection on embedded Python 3.13.15
refreshed in 5.14 seconds on rc7, versus 7.98 and 18.24 seconds in two rc6 runs.
Four criteria generated 4,404 evaluations in 3.13 seconds and refreshed in 4.64
seconds. A separate native run during packaging refreshed in 11.52 seconds.
Concurrent host work/cache conditions varied; these are indicative timings, not
a controlled speedup claim. The change shares file metadata only within a single
projection and preserves cross-refresh checks and freeze hashing. Multi-second
refresh remains a broader operation-UX limitation.

The locked unsigned build completed. All 302 top-level release-manifest entries
and 3,757 portable payload entries matched their hashes. No checked local-path
leakage was found. Two broad keyword matches are third-party RECORD hash text.
GUI/CLI PE subsystems are 2/3. Existing compiler unreachable-branch warnings come
from the shared GUI/CLI launcher compilation. An initial scan encountered the
installer while compilation still held it open; the completed-file rerun passed.
Prior rc2-rc6 manifests verified 1,512 unchanged files; fifteen historical v1/v2
artifacts verified unchanged. No historical artifact was rewritten.

These checks are local scripted verification, not fresh-Windows or human
usability/accessibility certification. Existing broad layout/high-DPI limitations
and final distribution acceptance gates remain open. No detector/model/threshold
default was introduced. Signing is intentionally deferred suite-level work;
Windows may show Unknown Publisher or SmartScreen warnings. Hashes establish
byte identity, not publisher identity. Nothing is tagged, uploaded or published.
