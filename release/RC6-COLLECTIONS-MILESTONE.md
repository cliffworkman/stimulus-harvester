# 0.2.0rc6 collections development milestone

Arc B adds provenance-based collection membership, query/run lineage, independent
human reviews, scoped deterministic screening and collection-aware immutable
freezes. Cliff's adopted Lucien directions explicitly approved independent
collection review identity and the versioned freeze contract. Codex implemented
and verified the changes. Scripted checks are not human usability acceptance.

Legacy project reviews and version-1 artifacts retain their meanings. Collection
reviews never inherit project or other-collection decisions. New activations and
changed registered assets need new reviews; rename/archive/restore preserve the
activation. Collection freezes use version 2 with explicit semantic dispatch and
capture the exact decision, policy, membership and source context. No detector or
threshold defaults, generalized screening, search continuation, unreviewed snapshots
or composed packages are introduced. See docs/collections.md.

This is an internal milestone candidate, not completion of every Checkpoint 8
release gate. Existing high-DPI/small-screen and accessibility limitations remain.
Genuine fresh-Windows acceptance, broader human usability/accessibility and final
distribution authorization are not replaced by local packaged tests. rc2–rc5
artifacts remain preserved; no tag, release upload or announcement is authorized.

Stimulus Harvester's current Windows builds are unsigned. Windows may display an
Unknown Publisher or SmartScreen warning. Code signing is intentionally deferred
while distribution infrastructure is being reconciled across the Stimulus
Modernization Suite. Hashes establish byte identity, not publisher identity.
Final public release authorization applies to exact unsigned bytes, hashes,
documentation and destination.

## Short milestone calibration

Use a test copy of a project. Create Prison interiors and Church interiors with
two phrases each. Search in one collection, or add a few existing images through
Collections → Add selected images to. Add one image to both collections; Accept
it in one and Reject it in the other. Switch collections and confirm the intended
decision is obvious. Inspect the image's collection/source details. Optionally
validate a collection freeze to see unresolved members and their review links.
Stop when collection selection, assignment, reviewing or understanding a blocker
becomes cumbersome. No need to repeat the entire six-stage scientific workflow.
